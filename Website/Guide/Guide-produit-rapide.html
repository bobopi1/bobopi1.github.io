Ajouter un produit dans Shopify sans casser le builder

Remplissez la fiche produit dans Shopify une seule fois. Le site lit ensuite ces champs pour afficher les boutons, les images, les prix, les dimensions et le reste automatiquement.

Ce que Shopify alimente

Titre et description

  • Titre du produit
  • Description du produit

Le site l’utilise pour

  • Le nom affiché dans le builder et sur la page produit
  • Le texte de présentation sur la fiche produit

Médias

  • Photos produit
  • Photos de variante si le visuel change selon le choix

Le site l’utilise pour

  • Les miniatures, la grande image et le popup “Voir le produit”
  • L’image de la variante sélectionnée quand elle existe

Tarification

  • Prix
  • Prix avant réduction si vous en utilisez un

Le site l’utilise pour

  • Le prix affiché dans le builder, la boutique et le panier
  • Le montant de la variante choisie

Variantes

  • Nom de l’option
  • Valeurs de l’option
  • Exemples : taille, couleur, type d’installation, matériau

Le site l’utilise pour

  • Les boutons de sélection dans le builder
  • Les listes déroulantes, les cartes de design et les variantes du panier

Champs méta

  • Width, Length, Height
  • Dimensions
  • Countertop_dimensions
  • Material, Countertop_Material
  • note

Le site l’utilise pour

  • Afficher les dimensions et les matériaux dans la fiche produit et le popup du builder
  • Afficher la note du type “Comptoir inclus”

Organisation du produit

  • Type
  • Balises

Le site l’utilise pour

  • Classer le produit dans la bonne catégorie du builder
  • Filtrer, regrouper et retrouver plus facilement les produits

À vérifier avant de publier

1. Titre Le nom du produit est clair et cohérent.
2. Type Le produit est dans la bonne catégorie : Vanité, Douche, Baignoire ou Toilette.
3. Variantes Les Nom de l’option et Valeurs de l’option correspondent aux choix du builder.
4. Médias Les bonnes images sont attachées au produit et aux variantes.
5. Champs méta Les dimensions, matériaux et notes sont remplis.

Si le produit est en solde

  • Dans la variante concernée, entrez le prix réduit dans Prix.
  • Entrez le prix original dans Prix avant réduction.
  • Exemple : Prix = 900,00 $ et Prix avant réduction = 1 000,00 $.
  • Si Prix avant réduction est vide, le site affichera seulement le prix soldé sans le prix barré.
Règle simple : Shopify contient l’information et le site la présente. Si un champ est vide ou mal nommé, le builder ne peut pas l’utiliser correctement.
Les libellés ci-dessus suivent les mots-clés Shopify utilisés dans notre boutique : Titre, Description, Médias, Tarification, Variantes, Champs méta, Organisation du produit, Type et Balises.
