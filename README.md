# GitHub Pages setup

This repository is ready for GitHub Pages.

## What to upload

- Keep the `Website/` folder as-is.
- Upload the repo root files too, especially `index.html` and `.nojekyll`.

## How to publish on GitHub Pages

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to **Pages**.
4. Set the source to the main branch and the repository root.
5. Save and wait for GitHub Pages to publish the site.

## Where the site lives

- Main site: `Website/index.html`
- Root page: `index.html` redirects visitors into the site folder

If you later want a cleaner Pages setup, you can move the contents of `Website/` into the repository root and remove the redirect page.
